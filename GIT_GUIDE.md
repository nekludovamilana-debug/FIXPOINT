# Работа с Git

В архиве находится локальный Git-репозиторий с историей начального коммита. Чтобы отправить его в удалённый репозиторий:

```bash
git remote add origin https://github.com/ВАШ_АККАУНТ/RepairWorkshop.git
git branch -M main
git push -u origin main
```

Сначала создайте пустой репозиторий на выбранной платформе (например, GitHub), затем замените URL на адрес своего репозитория. Не добавляйте в Git файл `.env`, пользовательскую базу `db.sqlite3` и загруженные клиентами фотографии.
