FIXPOINT — Система управления ремонтной мастерской

О проекте

FIXPOINT — веб-приложение для автоматизации работы ремонтной мастерской. Система предназначена для учёта заявок на ремонт, управления услугами, контроля запчастей и отслеживания хода выполнения заказов.

Основные возможности

Регистрация и авторизация пользователей.
Создание и обработка заявок на ремонт.
Управление статусами заявок.
Управление услугами мастерской.
Учёт запчастей и складских остатков.
Назначение мастеров на заявки.
История изменений статусов заявок.
Добавление комментариев к заявкам.
Формирование отчётов.
Роли пользователей

Клиент — создание заявок и просмотр их статуса.
Мастер — работа с заявками, изменение статусов и добавление комментариев.
Администратор — управление пользователями, услугами, складом и заявками.
